## 📌 Project Overview

Rouhi Store is a responsive e-commerce website designed for an LG home appliances store.

The project includes multiple responsive pages and interactive web components designed for a better user experience across desktop, tablet, and mobile devices.

## 👨‍💻 My Role

I was responsible for approximately 80% of the project, including:

* Designing and developing website pages
* Implementing responsive layouts
* Developing interactive elements with JavaScript
* Styling and structuring the user interface
* Testing the website across different screen sizes
